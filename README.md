# EduExam Portal — Frontend (GitHub Pages)

Frontend statis (HTML/CSS/JS vanilla) untuk EduExam Portal. Backend: Google Apps Script (`Kode.gs`, file terpisah).

1. Isi `GAS_URL` di `js/config.js` dengan URL Web App (`.../exec`).
2. Push isi folder ini ke repository GitHub → aktifkan Pages (branch `main`, folder `/root`).
3. Selama `GAS_URL` belum diisi, aplikasi berjalan dalam **MODE DEMO** (data contoh). Masuk demo: Siswa PIN `123456` · Guru `demo/demo` · Admin `admin/admin`.

Panduan lengkap: lihat `PANDUAN-INSTALASI.md`.
